# スライドのやることリスト

更新日：2026年11月2日。研究方針版：v1.7。

チェック済みは記載した範囲だけの完了を示す。準備済みと研究実験の完了を区別する。

## 準備済みの参照先

- [x] [参照資料の入口](references/README.md)を配置した。内容の最終確定や結果の登録とは別。
- [x] [発表根拠の対応表](発表根拠の対応表.md)を配置した。内容の最終確定や結果の登録とは別。

## 実施する作業

- [ ] 01 発表日、持ち時間、提出形式と掲載範囲を確認する。
- [ ] 02 現在の計画、実施状況、未実施の範囲から説明の順番を決める。
- [ ] 03 P12とP13の保存集計、P14の考察を確認して掲載結果を選ぶ。
- [ ] 04 各主張、表、グラフ、画像を実行IDと成果物または原典へ対応付ける。
- [ ] 05 保存した集計から図表を作り、対象、分母、条件と失敗の扱いを併記する。
- [ ] 06 学習前後の改善と悪化、論文手法との差、作業時間と修正後品質を説明する。
- [ ] 07 過去の本人資料を参照し、今回の実測や現在の条件と混同しない。
- [ ] 08 編集可能なPowerPointへ書き出し、数値、出典と画像の対応を照合する。
- [ ] 09 描画したスライドのはみ出し、文字、図表の可読性を確認する。
- [ ] 10 実際に通して発表時間を測り、内容と発話を調整する。
- [ ] 11 完成版と元ソース、根拠、残る課題を対応付けて保存する。

詳しい進め方は[やること.md](やること.md)を参照する。

完了にした項目には成果物または実行IDへのリンクを添える。工程全体の状態、未決事項、次の作業が変わったら状態JSONと日報も更新する。
