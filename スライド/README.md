# 第2回ゼミ研究報告のWebスライド

現在の入口は`seminar.md`。前回10月19日のゼミ資料の書き方を参考に、目的、全体像と今回の対象、処理、比較、評価、現在地をまとめた準備版。表紙、もくじ、5章の扉を含む本編51枚と付録9枚の全60枚。33〜39枚目は数値が空欄の結果枠で未測定、40〜47枚目は実験ごとの考察の枠で未記入。
6月8日の英論①と前回ゼミ正式版を参照し、9〜12枚目を「前回からの接続→手作業による映像選別の課題→先行研究との条件差→研究全体での今回の対象」の順にした。14枚目では課題と今回の取り組みを対応付ける。[参照箇所と判断](references/英論①_課題と接続の確認_20261103.md)。
実験結果が必要なページは未作成で、未測定の数値は掲載していない。
4:3、白背景、メイリオ、オレンジの見出し線と強調文字、灰色の図表、5章名（現在の章だけ白）、氏名と大学名、ページ番号を入れたオレンジの下端帯を使用する。各ページの章はseminar.mdのfrontmatterの`chapter`で指定する。
11月4日の本人の指定により、処理図の強調ボックスは白に近いオレンジ（#fff4eb）の塗りと濃いオレンジの縁、黒い太字にした。10・12・17枚目に適用し、11枚目では「今回」の列全体をオレンジ枠で囲む。文字の中央揃え・左揃えは維持する。[追加指定](references/README.md#図と比較表の強調に関する追加指定2026年11月4日)。
11月3日の本人の指摘を受け、前回PPTXの実物を基準に表紙、目次、目的ページ、表の行間と列の揃え方、下部のまとめを修正した。
研究目的ページは前回の文字と画像を配置とトリミング、顔の被覆を保って再構成している。
参照元から取り出した画像はGit対象外の`public/local-reference/`へ保存し、公開リポジトリには含めない。
Slidev 53.0.0、Node.js 24.22系を使用する。今回の動作確認は24.22.1で行った。

## 起動・書き出し

```powershell
.\project.ps1 dev
```

表示先は`http://localhost:3032/`。`project.ps1 build`で静的Web版を生成する。
依存関係がない環境では、対応するNode.jsで`npm ci`を実行する。
今回の依存関係は既存の中間発表フォルダと同版のnode_modulesをローカルのジャンクションで参照した。研究スライドの原稿とスタイルはこのフォルダ内に保存する。
現在のPowerPoint版はWeb版の提案手法と各手法の解説を反映する前の[全37枚・標準表版](exports/seminar-02-native-tables-20261104.pptx)。13個の表をセル単位で編集できるPowerPoint標準の表に置き換え、全セルの本文・行列の一致とPowerPointでの全ページ描画を確認した。11枚目のテスト用コピーでセルの編集・保存・再読込も確認した。
11月3日の[旧18枚版](exports/seminar-02-editable.pptx)は履歴として保持する。旧方式では表が文字と図形に分かれており、標準の表ではなかった。
本文と表は編集可能。SVGで作った全体図と区間図は画像として入るため、それらの編集はWebの元部品から行う。PDFは未出力。
Slidevの出力で見出しが上へずれる問題と、存在しないマスターの宣言を[scripts/finalize_seminar_pptx.py](scripts/finalize_seminar_pptx.py)で補正した。
再出力は`project.ps1 export`を使う。[export_native_pptx.ps1](scripts/export_native_pptx.ps1)が原出力を保持し、見出しの補正、Web表の取得、PowerPoint標準の表への置換、全セル本文・行列の検査を行い、日時付きの新しいファイルをexportsへ保存する。PowerPointのインストールが必要。
11月4日の原出力、表の取得情報、検査結果、PowerPointの確認画像はGit対象外の`../local_data/pptx_export_20261104_native_tables/`にある。旧18枚版の記録は`../local_data/pptx_export_20261103/`へ保持する。
出力PPTXは参照写真を含むためGit対象外でローカルに保持する。

## ファイル

- `seminar.md`: 現在のゼミ本編51枚（各章の先頭に扉。4〜6枚目は前回正式版4〜6ページの研究背景）と付録9枚（52枚目の扉、53〜56枚目GMs・GMA、57〜60枚目キーポイント指標）。付録は前回正式版の付録54〜57、59〜62を今回の書式へ移したもの。実験結果がそろったら結果と考察のページを追加する
- `components/BackgroundBirthChart.vue`: 研究背景の低出生体重児の出生数と割合のグラフ。値は前回PPTXの埋め込みデータ
- `scripts/extract_reference_pictures.py`: 前回PPTXから画像の位置とグラフの値を取り出す。顔を被覆した写真は前回発表版のページ画像から切り出す
- `public/images/appendix/`: 付録のGMs・GMA説明用イラスト。前回作成のAI生成画像（実在の児や症例ではない）を4枚に切り出した
- `slides.md`: 以前の中間発表用たたき台。現在の起動コマンドでは使用しない
- `seminar.css`, `layouts/seminar.vue`, `layouts/seminar-cover.vue`: 今回の4:3レイアウトと書式
- `components/`: 研究全体図と区間化の説明図。本文とともにソースから編集できる
- `発表日程と確認事項.md`: Gmailで確認した中間報告の日程、未確認事項、参照メール
- `style.css`: 共通スタイル。今回用のseminar.cssも読み込む
- [references/README.md](references/README.md): 参照資料の入口。本人の過去資料、他の発表参考、共通ルールを分けて管理
- `public/`: スライドへ載せる図・画像・動画
- `layouts/lecture.vue`: 富士通資料の本文ページに合わせた共通レイアウト
- `layouts/title-cover.vue`, `layouts/chapter-divider.vue`: 表紙と章扉のレイアウト
- `exports/`: PowerPointなどの書き出し先

## 引き継いだ制作ルール

数値、画像、結論は保存結果と条件を照合する。論文の報告、自分の実装、追加した変更、保存済み結果、未実施を区別する。研究室映像の予測を正解なしに精度と呼ばない。編集可能な本文は句点「。」を避ける。結果画像は元の縦横比を保ち、同じ条件で比較する。表示できたことをもって、結果や画面の正確さを確認済みとはしない。

詳細は[参照資料の入口](references/README.md)から共通ルールを確認する。
`references/過去の本人資料/`にある当時のAI指示書は制作履歴として扱い、現在の研究条件やスライド構成へ自動適用しない。
