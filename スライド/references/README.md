### 図と比較表の強調に関する追加指定（2026年11月4日）

本人の指示により、図の対象を目立たせるときは、文字色だけでなくボックスの塗りや枠を使う。
基本の灰色に対する強調として、処理図の対象ボックスは白に近いオレンジ（#fff4eb）で塗り、濃いオレンジ（#ed7d31）の縁と黒い太字を使う。同日の本人の追加指定により、当初の#f8cbadから塗りを薄くした。
比較表は強調する列全体をオレンジの四角い枠で囲む。中央揃えと左揃えの分け方は本人確認済みで、今の指定を維持する。
Web版10枚目の人が行う区間指定、12枚目の今回の対象、17枚目の区間候補への変換に塗りを使い、11枚目の「今回」の列を枠で囲んだ。
この追加指定は、すべての図表を一律に灰色だけで描くという解釈に優先する。
同日の追加指定により、11枚目の比較表は上段の列見出しと左端の行見出しを同じ灰色（#d9d9d9）・黒い太字で示す。左端は種類のデータではなく比較する観点の見出しとして扱う。波線は発言の取り違えによって追加したもので、本人の指摘を受けて削除した。区切りは通常の直線の罫線とする。
PowerPointへ出力する表は、画像や文字・四角の寄せ集めではなく、セル単位で編集できるPowerPoint標準の表を使う。標準の表かどうか、行列とセル本文の一致、PowerPointでの描画と代表セルの編集・保存・再読込を確認する。

前回資料の配色や揃えと差がある場合も、この指定を優先する。

各ページ下部は、本人が追加した画像を優先し、下端いっぱいにオレンジ帯（#e67214）を置く。
帯の右側に白い太字で「Hiroki Matsumoto,」「University of Miyazaki」、右端の濃いオレンジ欄（#984807）に白太字のページ番号を置く。
本文のまとめ文は帯の上に約20pt相当のオレンジ太字で中央配置する。表紙には帯を付けない。
画像の保存先はGit対象外の`local_data/presentation_reference_20261103/footer-reference.png`。この指定は直前の黒いページ番号の書式に優先する。
実装は共通部品の`components/SeminarFooter.vue`で管理する。

表紙は同日の本人の指定により、`D:/研究M1/中間発表/スライド/`の`layouts/title-cover.vue`と`style.css`を優先参照する。
中間発表の表紙をブラウザで確認し、題名、英語題名、細いオレンジ線、下部中央の氏名・ロゴ・所属の配置をゼミ版へ反映した。
