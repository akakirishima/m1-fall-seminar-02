# 発表根拠の対応表

更新日：2026年11月3日。現在のWeb原稿は全62枚（本編53枚・付録9枚）。目的、比較と評価、今回改訂した課題から取り組みへの接続の根拠を登録した。
今回の実データでの比較結果はまだなく、登録した内容は目的、前回資料、採用した構成、説明用の例、準備状況である。
現在のPowerPoint版は[全60枚・スライドマスター版](exports/seminar-02-native-tables-20261104-232525.pptx)。38個の表の標準表化、全セル本文・行列の一致とPowerPoint描画を確認した。これは資料の出力確認であり、研究モデルや科学的な主張の検証ではない。[当日の記録](../日報/2026-11-04.md)。

## 記録する内容

スライドの主張や図表ごとに、次の項目を登録する。
ページ番号が変わっても追跡できるよう、スライドまたは主張の識別IDを使う。

| 項目 | 内容 |
|---|---|
| 識別IDと対象スライド | 主張または図表とスライドを対応付ける |
| 種別 | 自分の実測、文献、計画、説明用の例を区別する |
| 主張 | 何を確認したと説明するか |
| 元の実行ID | 学習、推論、採点などの根拠 |
| 集計実行IDと成果物 | 表やグラフを生成した実行と出力先 |
| 条件と限界 | 対象患者、データ版、設定、原典との差、未測定の項目 |
| 確認状況 | 数値と画像の照合、内容確認、再現確認を区別する |
| 原典 | 文献に基づく主張の題名、著者、年、DOIまたは識別子 |

ここにはメトリクスを重複して手入力せず、正本の実行出力への参照を置く。
機微な成果物の実パスは記載せず、安全なIDで参照する。
登録のない結果を自動的に根拠ありとは扱わない。
