# M1後期第2回ゼミ

このフォルダでは、乳児映像の介入検知を中心とした研究計画、調査、実験、発表資料を管理する。
身体部位分割との関係を含め、現在の研究方針は[研究全体像](研究全体像.md)にまとめる。

## 読む順番

1. AIは[research_state.json](research_state.json)と[experiment_index.json](experiment_index.json)から現在地と実験を確認する。
2. [AGENTS.md](AGENTS.md)と[AI向け記録形式](共通/AI向け記録形式.md)に従い、必要な文書と実行記録だけを読む。
3. 研究の目的と判断の理由は[研究全体像](研究全体像.md)、変更履歴、[日報](日報/2026-10-30.md)で確認する。
4. [使用OSSと出典](共通/使用OSSと出典.md)に採用状況を記録する。

AIの開始時には`python research_tools/ai_records.py context`を使える。
記録を追加したら`index`、`check`を順に実行する。
この仕組みは状態と記録の読み取りを支援するもので、モデル実験の自動実行は未統合。

## GitHubでの管理

本人の依頼に基づき、[akakirishima/m1-fall-seminar-02](https://github.com/akakirishima/m1-fall-seminar-02)を非公開リポジトリとして使う。
2026年10月30日の管理構成整備時点ではGit未初期化だったが、その後の依頼でGitHub管理を追加した。

研究管理文書、確認コード、実行記録の小さなJSON、スライドのソース、自作の編集可能PowerPointを管理対象にする。
元動画、学習画像、正解ラベル、モデル重み、ローカル対応表はデータ用の除外フォルダへ置き、GitHubへアップロードしない。
認証情報、依存パッケージ、生成した確認用画像も`.gitignore`で除外する。
参考資料のPowerPoint2本には動画が埋め込まれているため、`スライド/references/`配下のPowerPointはサブフォルダも含めてアップロードせずローカルに保持する。
既存の参考資料そのものを、このリポジトリから取得できるとは扱わない。
GitHub管理の追加に、モデル重み取得や実験用パッケージの導入は含めない。

## 作業から発表まで

各P工程のフォルダで作業し、コードと設定は工程内へ、実行ごとの記録は工程内の`runs/<実行ID>/`へ残す。
保存した結果を確認し、[発表根拠の対応表](スライド/発表根拠の対応表.md)で主張と成果物を対応付けてからPowerPointを作成する。
詳細は[共通の作業運用](共通/作業フォルダと発表根拠の運用.md)を参照する。
フォルダの登録先は状態JSON、実行の一覧は派生する実験索引で管理する。
