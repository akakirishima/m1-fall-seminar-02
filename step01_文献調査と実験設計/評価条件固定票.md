## 指標の実装前仕様案

フレーム単位の主指標案は陽性の再現率とF1とし、適合率と非介入での誤検知率を併記する。
TP、FP、FN、TNと分母を患者別および全体で保存する。
分母ゼロは0点や満点に置き換えずNAとし、平均へ含めた患者数を明記する。
M2−M1などの差は同じ患者同士で算出し、患者を再標本化する信頼区間は患者数が確保できた場合に検討する。
連続フレームを独立標本として有意差を主張しない。

正解のuncertainは二値指標の対象外とし、全注釈時間に占める秒数を別に報告する案とする。
予測の判定不能、形式違反、処理失敗は全件保存し、二値正解を持つ対象でどれだけ生じたかを示す。
正常回答だけの指標には回答率を添え、全対象の指標として示さない。
失敗を人が確認する運用と、自動で全件判断する成績は別表にする。

**時間に基づく評価**では、正解陽性の時間集合をG、自動で除外する時間集合をE、二値正解がある範囲をDとする。
区間の長さを | | で表す。

- 残る介入秒数：`|G \ E|`。残した範囲での混入率：`|G \ E| / |D \ E|`。
- 介入時間の残存率：`|G \ E| / |G|`。
- 余計に除外した非介入秒数：`|E ∩ (D \ G)|`。その割合：`|E ∩ (D \ G)| / |D \ G|`。

判定不能の時間集合と人の確認後の結果を別に保存する。
時刻付きフレームしかない場合、区間境界への変換規則を固定するまで連続時間の値を算出しない。
抽出間隔より短い介入は、抽出フレーム上の評価だけでは見えないため、連続区間の正解で取りこぼしを確認する。

区間評価では「正解区間に1秒でも重なった」を十分な検出と同一視しない。
重なりがゼロの完全見逃しに加え、各正解区間の被覆率 `|G_i ∩ E| / |G_i|` を示す案とする。
対応付きの開始終了誤差を示す場合は、一対一の対応規則、必要な重なり、分割や結合の扱いを先に固定する。

## 人の作業時間の比較案

同じ作業者が同じ動画を直後に繰り返して、手作業と修正の速さを比較しない。
可能なら患者や場面を釣り合わせた複数セットを作り、作業者間で手順とセットを入れ替える。
一人だけの場合は未視聴の別セット、順序、既視聴の有無、実施日の間隔を記録し、慣れの影響を制約として示す。
完成ラベルは可能な範囲で別の人が確認し、誤りが残った短い作業を時間短縮として扱わない。

人の時間は準備、注釈、確認修正、再確認を分け、計算の経過時間と別に示す。
初期の人件時間差をΔC、動画1時間当たりの人の節約時間をΔtとすると、`ΔC / Δt` が損益分岐の処理動画時間の目安となる。
Δtが0以下なら、この条件で人の作業時間による回収点は得られない。

## 固定後の変更

本評価を見て設定を変える場合、その評価データは以後の開発に使ったものとして扱う。
変更理由、影響する実行、設定の新版を記録し、手つかずの患者で評価できるかを再設計する。
