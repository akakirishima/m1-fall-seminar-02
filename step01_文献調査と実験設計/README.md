# step01 文献調査と実験設計

## 目的

比較対象の文献、介入の定義、評価方法、使うモデルと実行環境を決める。

## 入力と出力

入力は[研究全体像](../研究全体像.md)、既存調査、確認した原典、使用可能な動画の情報とする。
出力は正式な書誌情報、採用モデル、ラベルと評価の規則、OSS一覧、動作確認の条件とする。

## 完了条件

引用の題名と識別子が一致し、比較する手法、入力、分割、指標、調整範囲、必要な環境が説明できる。
未決の条件が残る場合は、その条件に依存する本実験を完了扱いにしない。
