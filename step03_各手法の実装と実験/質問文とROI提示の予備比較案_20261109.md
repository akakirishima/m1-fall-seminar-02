# VLM質問文と固定ROI提示法の予備比較案

作成：2026年11月9日  
状態：**追加実験の提案・未実施**。主研究M0〜M3の比較設計や最終評価条件を変更・確定する文書ではない。

## 目的

研究目的は「固定ROI内に成人の手・腕が見える区間を候補化し、人が確認修正する負担を評価すること」。現在の質問案は「画像内に手または腕が見えるか」なので、固定ROIとの関係がモデル入力の中で明示されていない。

同一の開発用IR画像について、**質問文の具体性**と**ROIの画像への提示方式**を各2水準で比較し、M1で使う入力・質問候補を検討する。モデルが出した区間が本当に正しいかを評価する主実験とは分ける。

## 仮説（研究室IRで未検証）

- 詳細な除外条件が、乳児の手や寝具の誤検出を減らす可能性がある。ただし説明が長いことで見逃し、形式違反、推論時間が増える可能性もある。
- ROI内だけを表示すると関係のない領域に影響されにくくなる一方、成人かどうかの識別に必要な背景が失われる可能性がある。
- ROIの輪郭を残した元画像は文脈を保つが、Qwenが輪郭線を正確に解釈するとは限らない。

## 2×2比較（案）

| 条件 | 画像入力 | 質問 |
|---|---|---|
| A | 固定ROI外をマスクし、ROIを含む領域を切り出したIR画像 | 短い |
| B | Aと同じ画像入力 | 詳細 |
| C | 元IR画像に固定ROIの輪郭を赤線で重ねた画像 | 短い |
| D | Cと同じ画像入力 | 詳細 |

同一時刻の同一元フレームを4条件に使う。撮影環境ごとの `roi_id`、`roi_version` を保存する。ROIが多角形ならその形状を用い、外接矩形全体をROIと取り違えない。赤線の幅など描画仕様は最初に固定する。

**比較上の注意**：ROIマスクと元画像＋輪郭では、見える背景や手の大きさ・解像度も変わるため、この条件差を「線の有無だけの効果」とは呼ばず、入力表現全体の差として扱う。

## 質問候補（今回作成した研究用文案。論文からの転載ではない）

短い質問（ROIをどう提示したかを説明する共通前置きに続ける）：

> 指定したROI内に、成人の手または腕が見えますか。回答はpresent、absent、uncertainのいずれか1語だけにしてください。

詳細な質問（同じ共通前置きに続ける）：

> 指定したROI内に、成人の手または腕が視覚的に確認できるか判定してください。指先、手袋、腕の一部でも識別できればpresentです。乳児自身の手足、寝具、チューブ、反射、ROI外にのみある手や腕は対象にしないでください。成人のものか画像から判断できない場合はuncertainにしてください。接触や人物の職種を推測しないでください。回答はpresent、absent、uncertainのいずれか1語だけにしてください。

画像入力ごとの前置き：

- A/B：「この入力画像では固定ROIの外側をマスクしています。見えているROI内だけを判定してください。」
- C/D：「元画像の赤い輪郭線で囲った領域が固定ROIです。輪郭線の内側だけを判定してください。」

**留意**：現行の主ラベルは「成人の手や腕」であり、ここでは黙って「誰かの手」に定義変更しない。「乳児以外の人物」という言い換えを別の比較に入れるなら、対象の定義がどう変わるかを事前に検討する。

## 進め方と評価

1. P03：試行用に割り当てた開発患者の連続した短い動画を、人が元映像で `present / absent / uncertain` の時間区間として注釈する。最初の作業規模（例：2患者×15分）は工数の仮案であり、サンプルサイズ設計に基づくものではない。
2. P05：同じ時刻の画像を抽出しA〜Dへ変換する。最初の抽出間隔は1秒を候補とするが、正解区間のうち抽出画像がゼロ枚になる陽性区間も必ず数える。陽性画像だけでなく難しい陰性画像も含む。
3. M1（追加学習なしQwen）へ、同一基盤モデル・重み版・dtype・生成モード・生成長・バッチサイズ1で4条件を入力する。回答原文を保存し、`present / absent / uncertain / format_error / inference_error` を別に集計する。
4. 開発・調整用データでRecall、Precision、F1、ROI外の手・乳児の手の誤検出、uncertain率、出力形式違反、平均推論時間、患者別の傾向を比較する。
5. 元動画の正解陽性区間ごとに「抽出段階で陽性フレームが1枚もない」ものと「陽性フレームはあるがモデルが見逃した」ものを区別し、区間候補の完全見逃しと被覆時間も確認する。1秒・5秒・60秒などの抽出間隔比較は別の感度試験として記録する。
6. P08：再現率と完全見逃しを重視しつつ、余計な除外、判定不能率、推論時間を見て採用方式を決める。許容する完成品質の閾値は本評価前に指導者と固定する。
7. 採用後、M1とM2では質問文・ROI入力・前処理・区間化・推論条件を固定し、M2の追加学習効果を比較する。最終評価用患者で質問を選び直さない。

注釈・集計は自然な陽性率を保つ連続映像で評価する。連続したフレームを独立した患者数として数えない。判定不能と未注釈は陰性として扱わない。
