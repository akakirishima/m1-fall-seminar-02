# step03 各手法の実装と実験

## 目的

M1の学習なしVLM、M2の学習ありVLM、M3の論文に基づく分類法を実装し、条件と予測を保存する。
M0の手作業による正解と時間はstep02を参照する。

## 入力と出力

入力は共通のデータ分割、学習ラベル、モデル重み、固定した質問と設定。
出力は学習済み重み、各画像の予測、元動画の時刻との対応、時間とメモリ、実行記録。

## 構成

- `scripts/`：実装と保存済みの起動コード
- `configs/`：M1、M2、M3の条件
- `runs/<実行ID>/`：実行時コード、入力、設定、ログ、成果物

方式は設定内のmethod_idで識別する。
推論、追加学習、採点は別の実行として識別できるようにする。
外部のコードは出典と実行時の版を記録する。
