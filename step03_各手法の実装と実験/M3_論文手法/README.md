# M3 論文に基づくIR分類器

## 目的と現在地

本人確認済みの2021年「RGB-D scene analysis in the NICU」を基準に、IR条件で分類法を比較する。
現在は本文に基づく実装条件の確定前で、モデル用コード、学習、性能測定は未実施。

## 入力と出力

入力は原典と利用可能な原著コード、割当済みの試行画像、共通の学習ラベルと患者分割。
出力は原典との対応表、IRへの変更点、実装、学習済み重み、保存予測、調整履歴。
原論文の報告値と今回の実測を分ける。

## P06 実装と動作確認

- [ ] 入力、構造、初期重み、損失、学習条件、分割を原典と照合する。
- [ ] 確認できない条件と、IRへの適用で変更する条件を明記する。
- [ ] 少数入力でラベルと出力の対応、有限の損失、勾配更新を確認する。
- [ ] 重みを保存して再読込し、予測と時間を保存する。

## P09 共通データでの学習

- [ ] M2と学習患者、動画、ラベル、抽出対象を照合する。
- [ ] 学習条件の候補と上限を先に記録する。
- [ ] 学習と調整患者での選択を分け、採用重みと停止規則を保存する。
- [ ] 調整用の全対象で予測と失敗を残し、P11へ渡す。

## 完了条件と保存先

原典との差を説明でき、少数の更新と再読込が成立したらP06を完了とする。
採用重み、調整履歴、保存予測がそろったらP09を完了とする。
新規の専用実装と実行記録は、下記の担当P工程内で管理し、`method_id=M3`を記録する。
既存の親runsは移動しない。
Qwenの実装完了を待つ必要はない。
