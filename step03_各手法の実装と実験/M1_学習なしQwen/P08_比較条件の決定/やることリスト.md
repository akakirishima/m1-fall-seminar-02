# P08 学習なしQwenの比較用条件決定のやることリスト

更新日：2026年11月2日。研究方針版：v1.7。

チェック済みは記載した範囲だけの完了を示す。準備済みと研究実験の完了を区別する。

## 確認済みの準備

この工程の研究実行について、完了済みと判断できる作業はまだない。

## 実施する作業

- [ ] **P08-01** P04とP07を確認し、同じ基盤で学習前後を比較できることを確かめる。
- [ ] **P08-02** 調整患者と質問候補、変更範囲、試行上限を先に記録する。
- [ ] **P08-03** 調整患者だけで質問と推論条件を比較する。
- [ ] **P08-04** 入力IDごとの生成原文、解析結果、失敗と測定値を保存する。
- [ ] **P08-05** 見逃し、誤検知、形式違反と判定不能を調整患者で確認する。
- [ ] **P08-06** 採用する質問と推論条件を保存し、選択理由を記録する。
- [ ] **P08-07** 同じ質問、入力と推論条件をM2へ渡す。
- [ ] **P08-08** 共通条件を変更する場合のM1とM2の再測定範囲を記録し、P11へ渡す。

## 終了時の記録

- [ ] 成果物と実行ID、確認結果、失敗、未解決点をこのフォルダからたどれるようにする。
- [ ] 索引生成と記録検査を行い、日報と状態JSONの次の作業を更新する。

詳しい進め方は[やること.md](やること.md)を参照する。

完了にした項目には成果物または実行IDへのリンクを添える。工程全体の状態、未決事項、次の作業が変わったら状態JSONと日報も更新する。
