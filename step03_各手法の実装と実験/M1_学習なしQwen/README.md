# M1 学習なしQwen

## 目的と現在地

追加学習なしの基準を作り、同じQwenを追加学習するM2と比較する。
現在は未実行で、採用する基盤モデルと環境も未確定。

## 入力と出力

入力は割当済みの患者の画像、候補モデル、質問、共通の入力一覧。
出力は生成原文、解析したラベル、失敗状態、時間とメモリ、確定設定、実行記録。
実データと重みはGit対象外の保存先を参照する。

## P05 動作確認

- [ ] 環境、モデル版、依存版を保存する。
- [ ] 少数画像で読込と推論を実行する。
- [ ] 入力IDと生成原文を対応付け、回答不能と形式違反も保存する。
- [ ] 時間と最大メモリを測り、P07へ同じ基盤版を渡す。

## P08 比較用の条件決定

- [ ] P07の追加学習が成立した基盤モデルを主比較用に選ぶ。
- [ ] 調整患者だけで質問と推論条件を選び、変更履歴を保存する。
- [ ] 共通データの予測を保存し、M2と同じ入力と質問を照合する。
- [ ] 最終評価前にP11の固定票へ設定を渡す。

## 完了条件と保存先

少数の推論成功をP05の完了、調整用の予測と採用設定の保存をP08の完了とする。
最終評価患者での成績はP12に分ける。
新規の専用実装と実行記録は、下記の担当P工程内で管理し、`method_id=M1`を記録する。
既存の親runsは移動しない。
[全工程の計画](../../研究計画_詳細.md)と[環境確認手順](../環境確認と少数実験.md)を参照する。
