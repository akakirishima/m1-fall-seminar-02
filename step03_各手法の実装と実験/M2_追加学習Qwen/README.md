# M2 追加学習ありQwen

## 目的と現在地

M1と同じ基盤モデルへ追加学習し、追加学習の効果を検証する。
現在は学習経路、環境、基盤モデルの確定前で、学習と性能測定は未実施。

## 入力と出力

入力はM1と同じ基盤版、割当済みの学習画像、共通正解、M1と同じ質問と推論条件。
出力は更新対象と学習設定、重み、再読込の記録、予測、時間とメモリ、実行記録。
M3と学習対象を共有する。

## P07 少数の追加学習確認

- [ ] P05で推論できた基盤版の学習経路とライセンスを確認する。
- [ ] 学習患者の少数画像で画像入力、正解、損失対象を確認する。
- [ ] 有限の損失、勾配更新、更新対象と重みの変化を確認する。
- [ ] 保存した重みを新しいプロセスで再読込し、M1と同条件で推論する。

## P10 共通データでの追加学習

- [ ] P08の質問と推論条件を受け取り、M3との学習入力を照合する。
- [ ] 学習条件の候補、調整回数の上限、停止規則を先に記録する。
- [ ] 学習患者で重みを更新し、調整患者で重みを選ぶ。
- [ ] M1との条件差を検査し、採用重みと調整予測をP11へ渡す。

## 完了条件と保存先

更新、保存、再読込、同条件での推論まで成立したらP07を完了とする。
共通データで学習し、採用重みと調整予測がそろったらP10を完了とする。
M1より良くなることは完了条件に含めず、悪化や判定不能も保存する。
新規の専用実装と実行記録は、下記の担当P工程内で管理し、`method_id=M2`を記録する。
既存の親runsは移動しない。
[全工程の計画](../../研究計画_詳細.md)と[環境確認手順](../環境確認と少数実験.md)を参照する。
