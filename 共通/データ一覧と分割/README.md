# データ一覧と分割

状態：動画未選定。実データの一覧、ラベル、分割はまだ作成していない。

動画が決まったら、元の保存先、患者ID、動画ID、長さ、利用する区間、ファイルの識別情報を登録する。
生データ自体をこのフォルダへコピーする必要はない。
患者単位の分割一覧を版付きで保存し、各手法と実行から同じ一覧を参照する。

少数の試行用動画と、最終評価対象の使い分けを先に決める。
調整に使ったデータを、手つかずの最終評価データと呼ばない。
ラベル規則と分割を変更したら、元の版を残して新しい版を登録する。

## 登録の準備

[CSV仕様と実行方法](../../step02_正解データ作成/CSV仕様.md)と[空のひな型](../../step02_正解データ作成/templates/)を用意した。
実データの登録ファイルはGit対象外の`data/local/`など、許可されたローカル保存先で管理する。
検査済みという記録だけで分割の確定や注釈完了とは扱わない。

## AIからの参照

共有する構造化記録では、安全なdataset_id、version、必要な識別情報でデータを参照する。
実際の動画や画像、正解ラベル、患者対応表とパスはGitHubへ置かない。
ローカルの対応表は無視対象の`local_data/paths.json`に作る。
トップレベルをschema_versionとdatasets、datasetsの各項目をid、version、path、必要に応じてsha256とする。
実データが未選定の現在は対応表を作らず、research_state.jsonのdatasetsも空にする。
データIDやハッシュ自体に機微な情報がある場合も、その情報を共有記録に載せない。
