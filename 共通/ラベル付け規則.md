# ラベル付け規則

状態：ドラフト v0.2。実動画での試行は未実施。

## 検出対象

出発案は、乳児の映像に映る成人の手や腕の有無とする。
成人の映り込み、乳児への接触、運動解析を妨げる介入は別の概念である。
少数のラベル付けで違いを確かめ、主対象を確定する。
職種を判別できない映像から「看護師」と断定しない。

## 区間ラベルの案

| 項目 | 内容 |
|---|---|
| patient_id / video_id | 患者と元動画を対応付ける識別子 |
| start_s / end_s | 動画開始からの区間。秒で記録 |
| adult_hand_arm | present、absent、uncertain |
| contact_evidence | visible、not_visible、uncertain。主分類への採用は未決 |
| annotator / annotation_version | 作業者と規則の版 |
| note | 判断の根拠と迷った場面 |

`contact_evidence=not_visible`は、接触していないことの証明ではない。
ラベル付け済みの範囲を別に登録し、未注釈区間を自動的にabsentと扱わない。
区間は原則として開始を含み終了を含まない`[start_s, end_s)`とし、実装時に時刻とフレーム番号の変換を記録する。

## 試行で決めること

- 一部だけ映る手や腕、反射、成人か判断しにくいものの扱い
- 手が一瞬消える場合の区間のつなぎ方
- 出入りの境界と必要な時間精度
- 映像の再生速度、ツール、停止や巻き戻しの扱い
- 判定不能の理由と、学習データに含める範囲
- 別の人が独立に付ける確認範囲と、不一致を整理する方法

## 時間の記録

注釈に必要な人の操作時間、休憩、ツールの準備時間を区別する。
動画長、再生速度、対象区間、作業者、既視聴かどうかも残す。
学習用ラベルの作成時間と、新しい評価動画の作業時間を区別する。
自動判定後の修正時間は、同じ出力品質を目指す別の作業として測る。

## データ生成

元の区間注釈を共通の正解として保持し、そこから分類用とVLM用のデータを保存コードで生成する。
元動画の時刻、フレーム番号、抽出条件、ラベル規則の版を対応付ける。
実際の動画と作業ツールが決まるまで、注釈済みデータや件数を作ったことにしない。

## 区間をまとめて付ける操作

本人の希望に従い、人の入力は状態が続く時間区間単位とする。
抽出画像のラベルは区間と時刻の対応から生成する。
[区間注釈とクラス比率](../step02_正解データ作成/区間注釈とクラス比率.md)に、操作、集計の単位、学習用比率の検証案をまとめた。
境界精度や不明場面の定義は引き続き実動画での試行後に確定する。

## ROIを用いる場合の詳細案

[ROI区間注釈のルール案](../step02_正解データ作成/ROI区間注釈のルール案.md)を作成した。
全画面のadult_hand_armとROI内の手の有無は別定義として保持し、詳細案の採用が決まるまで既存CSVの意味は変更しない。

## 最新の入力方式

本人の最新希望に基づき、当面の入力は画像1枚ずつのボタン／キー入力とする。
区間入力についての上記記述は以前の検討案として保持する。
[自作ツール](../step02_正解データ作成/annotation-app/README.md)では全画面とROI内を明示的に区別する。区間からの展開や動画からの抽出は未実装。
ラベルの意味と境界例の確定には、引き続き実画像での試行が必要。

## 2026年11月2日の入力方法追加

本人の依頼で[動画区間モード](../step02_正解データ作成/annotation-app/動画区間モード.md)を追加した。画像入力と区間入力を選べる。
未注釈の隙間は陰性に変換せず、動画の秒単位の区間を保存する。入力方法の追加で、検出対象や評価規則の確定とは区別する。
