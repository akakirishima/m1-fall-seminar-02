# 少数動画による注釈試行

状態：準備済みの手順案 v0.1。実動画での実施はまだない。
データの所在と利用条件が確認できた後に使う。

## 試行前の登録

1. 患者対応を確認し、匿名のpatient_idとvideo_idを登録する。同一患者の別撮影を別患者として数えない。
2. 試行に使った患者をpilotへ割り当てる。後からtrainまたはdevとして使う場合は分割版を改め、testへは入れない。
3. 元動画を変更せず、保存先、SHA-256、動画長、時刻原点を動画一覧へ記録する。個人情報を含む原ファイル名と対応表は研究室の指定場所で保持する。
4. [CSV仕様](CSV仕様.md)のひな型を作業場所へコピーする。Gitには空のひな型のみを置く。

## ツールを試す

区間単位の操作に合うELANを最初の試行候補とする。
[公式資料と未確認点](../step01_文献調査と実験設計/文献確認表.md)を参照し、導入後に使用版を記録する。
再生、コマ送り、開始終了の指定、ラベルの訂正、保存、再読込、表形式の出力を試す。
元動画と書き出し時刻を開始付近、中間、終了付近で照合し、オフセットや単位のずれがあれば解消する。
ELANの書き出しを本研究CSVと同じ形式と仮定せず、列対応と変換手順を保存する。

## 1回目の注釈

先に注釈する連続範囲を決め、視聴した範囲をcoverage.csvへ登録する。
その範囲の全時間をpresent、absent、uncertainのいずれかで覆う。
区間の隙間を自動的にabsentにせず、未完了として扱う。
連続範囲を選ぶ際に映り込みがある場面だけへ偏らせず、自然な陽性率の記録を残す。

| 場面 | 試行時の記録案 | 規則の確定時に決めること |
|---|---|---|
| 成人の手や腕が明瞭 | present、見える範囲を記録 | 入り始めと出終わりの境界 |
| 指先や腕の端だけ | 見分けられればpresent、迷えばuncertain | 最小の可視部分 |
| 寝具、ケーブル、反射との混同 | uncertainと理由 | 観察可能な根拠 |
| 手が一瞬消える | 出現区間を分けて記録 | 後処理で結合する時間幅 |
| 手が映らないが寝具が動く | 手の有無と接触の判断を分ける | 映り込み課題で観測できない介入 |
| 成人の手が見えるが接触不明 | present、contact_evidence=uncertain | 主対象と補助項目の使い分け |

規則変更前のラベルは残す。
contact_evidenceのnot_visibleは接触なしの断定として使わない。

## 独立確認と時間計測

可能なら別の作業者が同じ範囲を、最初のラベルやモデル出力を見ずに注釈する。
協力者がいない場合は日を空けた自己再注釈を候補とし、作業者間一致とは呼ばない。
一致率だけでなく、present同士の時間の重なり、不一致秒数、境界の差、uncertainの理由を確認する。
不一致解消後の合意ラベルと、独立注釈の原本を分けて保存する。

開始終了の壁時計時刻、準備、操作、休憩、再確認の秒数を記録する。
再生速度、既視聴の有無、ツール版、規則版も残す。
モデルの提案を見ながら作ったラベルを、モデルから独立した初回の正解として扱わない。

## 試行後の判断

- 患者別の動画時間、present/absent/uncertain秒数、映り込み区間数、短い区間の長さ分布を集める。
- 注釈速度と不一致を基に、本注釈の対象時間と必要人数を見積もる。
- 映り込みと接触などがずれる事例を示し、研究目的に合う主対象を確定する。
- 最短の介入と境界の不一致を見て、抽出間隔と境界精度を決める。
- 規則を更新し、患者単位の分割と評価条件を固定してから本注釈へ進む。

ラベル検査コードは形式、患者の混入、範囲の矛盾を確認する。
映像上の正しさやデータ利用の可否は、人による確認が必要である。
