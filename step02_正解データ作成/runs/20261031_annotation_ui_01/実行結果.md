# ローカル画像注釈ツールのブラウザ確認

実施日：2026年10月31日。研究モデルや実データの注釈ではなく、自作ツールのUI確認。

入力は640×480の単色PNG3枚。生成方法は[確認時のコード](code_snapshot/run_smoke.py)に保存した。
Playwright CLIとChromiumを使い、[操作コード](code_snapshot/browser-smoke.js)の一連の操作が終了コード0で完了した。
[出力記録](browser-output.txt)とローカルの確認画像`output/playwright/annotation-smoke.png`を確認した。
保存したJSONのラベル数3とROIの存在、CSVのpresent/absent/uncertain各1行もPythonで照合し成功した。

確認した操作は、画像の選択、共通ROIの描画とロック、1/2キーと自動次送り、理由なしの判定不能の拒否、理由付きの入力、画像枚数と50%の表示、JSONとCSVのダウンロード、自動復元、キー変更、JSON読込、判定不能理由を消した場合のラベル解除。
ページのJavaScript例外は0。初期favicon未配置による404は空のfavicon指定で解消した。
最後にテスト用ブラウザのlocalStorageをクリアし、初期画面に戻した。

実動画のフレーム抽出、ROIの正しさ、患者の独立性、学習時の互換性、他のブラウザでの操作は未確認。
画像データ本体はサーバーに送らず、クライアント側のFile APIで扱う。
実際の作業は終了時にJSONも保存し、独立注釈や規則変更前の結果を別に保持する。
