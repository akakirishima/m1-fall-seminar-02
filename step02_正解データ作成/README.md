# step02 正解データ作成

## 目的

各手法で共通に使う正解と患者単位の分割を作り、手作業に必要な時間を記録する。

## 入力

利用可能な元動画、[ラベル付け規則](../共通/ラベル付け規則.md)、患者と動画の対応、選んだ注釈ツール。

## 出力

版付きの元動画一覧、区間ラベル、分割一覧、手作業時間、分類用とVLM用の派生データ。
元の区間注釈から派生データを生成したコードと実行記録も残す。

## 現在地

実データの注釈は未着手。動画と患者数は不明。最新依頼に従い、画像1枚ずつのボタン／キー入力ツールを自作し、ローカルで起動して合成画像で操作を確認した。区間用のVIA等は以前の検討候補。

- [ ] [注釈ツールの選定](注釈ツールの選定.md)に従い、既存ツールと必要な補助機能を確認する。
- [ ] 試行動画を選ぶ。
- [ ] 少数の注釈で迷う場面と時間を記録する。
- [ ] 可能な範囲で別の作業者の注釈と照合する。
- [ ] ラベル規則を確定する。
- [ ] 患者単位の分割を固定し、必要なラベルを作成する。
- [ ] 共通ラベルから各手法用のデータを生成し、対応と重複を確認する。

## 完了条件

注釈済み範囲と未注釈範囲が区別でき、患者の混入がなく、元動画から生成データまで追跡できる。
必要な件数を満たしたかは、患者数と介入区間数に基づいて判断する。
実験を始めるまでに、スクリプト、設定、実行ごとの`runs/`をこのステップへ追加する。

[起動と使い方](annotation-app/README.md)を参照する。共通ROI、1＝あり、2＝なし、判定不能、キー変更、自動次送り、JSON保存再開、CSV出力に対応する。
独自のフレーム用スキーマを使い、従来の区間CSVとは混在させない。
