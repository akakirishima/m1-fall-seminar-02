# P02 動画登録と試行患者の割当のやることリスト

更新日：2026年11月2日。研究方針版：v1.7。

チェック済みは記載した範囲だけの完了を示す。準備済みと研究実験の完了を区別する。

## 確認済みの準備

この工程の研究実行について、完了済みと判断できる作業はまだない。

## 実施する作業

- [ ] **P02-01** 動画の保存先と利用可能範囲を確認する。
- [ ] **P02-02** 患者と動画を対応付け、同一患者の複数動画を識別する。
- [ ] **P02-03** 元動画の長さ、撮影条件、形式、内容識別情報を登録する。
- [ ] **P02-04** 実パスと患者対応をGit対象外のローカル対応表へ保存する。
- [ ] **P02-05** フレーム抽出前に試行用患者を割り当て、用途を記録する。
- [ ] **P02-06** 試行と調整に使った患者を最終評価へ戻さない規則を確認する。
- [ ] **P02-07** 患者数から学習、調整、最終評価の独立性が成立しそうか整理する。
- [ ] **P02-08** 安全なデータIDと利用履歴を状態JSONへ登録し、P03へ渡す。

## 終了時の記録

- [ ] 成果物と実行ID、確認結果、失敗、未解決点をこのフォルダからたどれるようにする。
- [ ] 索引生成と記録検査を行い、日報と状態JSONの次の作業を更新する。

詳しい進め方は[やること.md](やること.md)を参照する。

完了にした項目には成果物または実行IDへのリンクを添える。工程全体の状態、未決事項、次の作業が変わったら状態JSONと日報も更新する。
