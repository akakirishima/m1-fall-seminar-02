# P13 手作業と確認修正の負担比較のやることリスト

更新日：2026年11月2日。研究方針版：v1.7。

チェック済みは記載した範囲だけの完了を示す。準備済みと研究実験の完了を区別する。

## 確認済みの準備

この工程の研究実行について、完了済みと判断できる作業はまだない。

## 実施する作業

- [ ] **P13-01** P11の対象セット、作業者、順序と既視聴の扱いを確認する。
- [ ] **P13-02** 各方式の固定出力を対象動画と対応付けて準備する。
- [ ] **P13-03** 手作業と確認修正の開始終了、休憩、準備と再確認を記録する。
- [ ] **P13-04** 区間の追加、削除、境界修正と必要な再視聴を記録する。
- [ ] **P13-05** 修正後のラベル品質を事前に決めた方法で確認する。
- [ ] **P13-06** M0の正解作成時間と未視聴対象での作業時間を区別する。
- [ ] **P13-07** 人の時間、計算時間、初期の注釈と学習費用を分けて集計する。
- [ ] **P13-08** 対象差、慣れ、確認者不在などの限界を記録する。
- [ ] **P13-09** 品質と時間の比較結果をP14と発表根拠へ渡す。

## 終了時の記録

- [ ] 成果物と実行ID、確認結果、失敗、未解決点をこのフォルダからたどれるようにする。
- [ ] 索引生成と記録検査を行い、日報と状態JSONの次の作業を更新する。

詳しい進め方は[やること.md](やること.md)を参照する。

完了にした項目には成果物または実行IDへのリンクを添える。工程全体の状態、未決事項、次の作業が変わったら状態JSONと日報も更新する。
