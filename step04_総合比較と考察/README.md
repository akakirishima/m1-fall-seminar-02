# step04 総合比較と考察

## 目的

同じ評価対象について精度、残る介入、除外しすぎた映像、時間、修正後の品質を比較する。

## 入力と出力

入力はstep02の正解と作業記録、step03の保存予測と実行記録。
出力は方式別と患者別の比較表、誤り分析、時間比較、根拠付きの考察、発表用の図。
保存結果を使う集計と、新しい推論を伴う実験を区別する。

## 現在地

未着手。評価方法はドラフトで、結果は存在しない。

- [ ] 評価対象、判定不能の扱い、区間化条件を固定する。
- [ ] 共通の保存予測と正解から指標を集計する。
- [ ] 患者別、場面別の誤りを確認する。
- [ ] 人による確認修正時間と出力品質を測る。
- [ ] 初期費用と動画一本あたりの費用を分けて比較する。
- [ ] 研究目的に対する効果と限界を整理し、スライドへ反映する。

## 完了条件

結論が比較条件と保存結果に対応し、未測定、原論文との差、データ規模による制約が明示されている。
元の予測、集計コード、出力、日報から結果をたどれる。
