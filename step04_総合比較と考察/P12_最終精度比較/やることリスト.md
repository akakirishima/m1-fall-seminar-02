## 確認済みの準備

この工程の研究実行について、完了済みと判断できる作業はまだない。

## 実施する作業

- [ ] **P12-01** P11の固定条件と評価用データの版、独立性を確認する。
- [ ] **P12-02** 手法ごとに新しい推論実行IDを作り、共通の全対象を処理する。
- [ ] **P12-03** 全予測、生成原文、判定不能、形式違反と処理失敗を保存する。
- [ ] **P12-04** 保存予測の入力IDと件数、欠落や重複を検査する。
- [ ] **P12-05** 固定した採点コードでフレーム指標と連続区間の指標を集計する。
- [ ] **P12-06** 患者別と全体の分母、回答率、失敗率、処理時間（モデルごとの全体の時間と1枚あたりの平均）とメモリを示す。
- [ ] **P12-07** M2対M1、M3対M1、M3対M2を同じ患者で比較する。
- [ ] **P12-08** 集計コードと出力を保存し、P14と発表根拠へ渡す。
- [ ] **P12-09** 結果を見た条件変更が必要なら新しい開発として扱い、最終評価の再利用を区別する。

## 終了時の記録

- [ ] 成果物と実行ID、確認結果、失敗、未解決点をこのフォルダからたどれるようにする。
- [ ] 索引生成と記録検査を行い、日報と状態JSONの次の作業を更新する。
